# Phase 2 — Data Structures and Algorithms Curriculum

> Comprehensive DSA curriculum for the adaptive-learning prototype.

## 1. Foundations & Complexity Analysis
- Programming foundations: variables, data types, operators, conditionals, loops, functions, pointers/references, memory, I/O, debugging
- Algorithm fundamentals: correctness, iterative vs recursive, deterministic vs randomized
- Time/space complexity; best/average/worst case; auxiliary space
- Big-O, Big-Theta, Big-Omega
- Amortized analysis
- Recurrence relations; substitution, recursion-tree, Master theorem

## 2. Arrays
- Static/dynamic arrays; 1D/2D arrays
- Traversal, insertion, deletion, searching, updating, rotation, reversal
- Prefix sums, difference arrays, sliding window, two pointers, frequency counting
- Kadane's algorithm, merge intervals, matrix/spiral traversal, in-place algorithms
- Common problems: missing/duplicate elements, two/three sum, subarray sum, majority element, stock buy/sell, product except self

## 3. Strings
- Character arrays, string operations, comparison, manipulation
- Substrings, subsequences, frequency counting, palindromes
- Naive pattern matching, KMP, Rabin-Karp, Z algorithm, prefix function
- Manacher's algorithm and string hashing

## 4. Linked Lists
- Singly, doubly, circular linked lists
- Traversal, insertion, deletion, searching, updating, reversal, merging, sorting
- Fast/slow pointers, Floyd cycle detection, middle node, nth from end
- Intersection, palindrome, merge sorted lists, reverse in groups

## 5. Stacks
- LIFO; push, pop, peek/top
- Array and linked-list implementations
- Parentheses matching, expression evaluation
- Infix/prefix/postfix conversion
- Call stack, undo/redo, backtracking
- Monotonic stacks: next greater/smaller, previous greater/smaller, histogram, stock span

## 6. Queues
- FIFO; enqueue, dequeue, front/rear
- Array and linked-list implementations
- Circular queue, deque, priority queue
- Scheduling, buffering, BFS, sliding-window applications

## 7. Hashing & Hash Tables
- Hash functions, hash tables, key-value mapping, load factor
- Collision handling: chaining, open addressing, linear/quadratic probing, double hashing
- Frequency maps, duplicate detection, two-sum, anagrams, prefix-sum hashing, caching
- Sets and maps

## 8. Recursion
- Base case, recursive case, call stack
- Tail/direct/indirect/multiple recursion
- Factorial, Fibonacci, power, arrays, strings, tree recursion
- Backtracking, divide and conquer, memoization
- Recursion-to-iteration conversion

## 9. Searching
- Linear/sequential search
- Binary search; lower/upper bound
- First/last occurrence, rotated arrays, binary search on answer
- Peak finding, 2D matrix search
- Ternary, interpolation, exponential search

## 10. Sorting
- Bubble, selection, insertion sort
- Merge sort, quick sort, heap sort
- Counting, radix, bucket sort
- Stable vs unstable; in-place vs out-of-place
- Comparison-based and external sorting; custom comparators

## 11. Trees
- Terminology: root, parent/child, leaf, depth, height, subtree, degree
- Binary trees and representations
- Preorder, inorder, postorder, level-order
- Recursive and iterative traversal
- Height, diameter, width, tree views, lowest common ancestor
- BST: search, insert, delete, min/max, predecessor/successor, validation
- AVL, Red-Black, Splay, B-tree, B+ tree

## 12. Heaps & Priority Queues
- Min/max heap, representation, heapify
- Insert, extract, peek, build heap, heap sort
- Priority queues
- Kth largest/smallest, Top-K, merge K sorted lists
- Median of a data stream

## 13. Tries
- Trie structure, insert, search, prefix search, delete
- Autocomplete, dictionaries, spell checking, prefix matching, word search
- Compressed trie, ternary search tree, bitwise trie

## 14. Graph Fundamentals
- Vertices, edges, directed/undirected, weighted/unweighted graphs
- Degree, paths, cycles, connected components
- Adjacency matrix, adjacency list, edge list
- BFS, DFS, iterative/recursive DFS
- Connected components and bipartite checking

## 19. Dynamic Programming

## 20. Backtracking

## 21. Bit Manipulation

## 36. Assessment Categories
For every concept assess:
- Conceptual understanding
- Terminology
- Implementation
- Tracing/execution
- Complexity analysis
- Error diagnosis
- Application
- Problem solving
- Transfer to unfamiliar problems
- Teach-back / Feynman explanation

Example — Stack:
```text
Concept → LIFO
        ↓
Operations → push / pop / peek
        ↓
Implementation → array / linked list
        ↓
Tracing → call stack
        ↓
Applications → expressions / backtracking
        ↓
Complexity → O(1) operations
        ↓
Problem solving → monotonic stack
        ↓
Teach-back → explain stack to the AI
```
