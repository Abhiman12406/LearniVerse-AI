# 01: Core Architecture & Navigable 3D Cyber Atrium

**What to build:** A learner can launch the application, load their learner profile from the backend, and control an Avatar using third-person WASD movement and mouse camera orbit to explore the central Atrium with ambient cyber lighting and Web Audio sound.

**Blocked by:** None (can start immediately)

**Status:** completed

- [x] Backend provides a learner profile endpoint returning learner ID, name, and current learning state
- [x] Frontend boots a full-screen React Three Fiber viewport with deep-tech cyber styling (obsidian architecture, emissive floor Conduits, selective bloom)
- [x] Learner controls an Avatar with smooth third-person WASD navigation, mouse camera orbit, and boundary collisions
- [x] Atrium features a Central Dais and radiating archways leading toward Wings
- [x] Subtle ambient sci-fi background drone plays with an instant HUD audio mute toggle
- [x] Automated tests verify learner profile loading and Avatar initial coordinate placement
